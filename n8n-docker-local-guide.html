n8n Container Run
အဓိက command — ဒါပဲ run ရမည်
🚀
n8n Docker container စတင်
docker run command
+
PowerShell — Administrator
docker run -d `
  --name n8n `
  --restart unless-stopped `
  -p 5678:5678 `
  -v "$HOME\.n8n:/home/node/.n8n" `
  -e GENERIC_TIMEZONE="Asia/Yangon" `
  -e TZ="Asia/Yangon" `
  docker.n8n.io/n8nio/n8n
⚠️ PowerShell မှာ line continuation character က backtick ` ဖြစ်သည် — copy ပြီး တစ်ကြောင်းတည်း ကူးထည့်နိုင်သည်
Terminal
docker run -d \
  --name n8n \
  --restart unless-stopped \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  -e GENERIC_TIMEZONE="Asia/Yangon" \
  -e TZ="Asia/Yangon" \
  docker.n8n.io/n8nio/n8n

Flag တစ်ခုချင်စီ ဘာလုပ်သလဲ

Flagအဓိပ္ပာယ်
-dBackground မှာ run — terminal ပိတ်လည်း n8n ဆက် run နေမည်
--name n8nContainer ကို "n8n" လို့ အမည်ပေး — နောက်မှာ ဒီအမည်နဲ့ control လုပ်မည်
--restart unless-stoppedPC restart တိုင်း n8n auto-start ဖြစ်မည်
-p 5678:5678PC port 5678 ကို container ထဲ map — browser ကနေ access ရမည်
-v ~/.n8n:...Step 3 မှာ ဆောက်ထားတဲ့ folder ကို container ထဲ mount — data ကျန်မည်
-e TZ=Asia/YangonMyanmar timezone သတ်မှတ် — workflow schedule မှန်ကန်ဖို့
