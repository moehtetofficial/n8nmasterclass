ရုံး
01
သင်ရုံးကို မသွားချင်တဲ့နေ့
သင် (သူဌေး) က ရုံး (n8n) ကို တိုက်ရိုက်သွားချင်တဲ့အချိန်မှ သွားတယ်။ ဒါပေမယ့် ရုံးကအလုပ်တွေ နေ့တိုင်းပုံမှန်လုပ်နေဖို့ လိုတယ်။ သင်မသွားနိုင်တဲ့နေ့မျိုးမှာ ဘယ်သူက ရုံးကိုသွားမလဲ?
02
Claude ကို ခိုင်းလိုက်
သင့် လက်တိုလက်တောင်း (Claude) ကို "ရုံးကိုသွားပြီး ဒီ workflow တွေ run ပေးပါ" လို့ ခိုင်းလိုက်ရုံပဲ။ Claude က ဘယ်တော့မဆို ၂၄/၇ အလုပ်လုပ်ပေးနိုင်တယ်။
03
MCP က တံခါးပေါက်
ဒါပေမယ့် Claude က ရုံး (n8n) ထဲဝင်ဖို့ Password လိုတယ်။ ထို Password ကို သင်က Claude အတွက် သီးသန့်ထုတ်ပေးထားရတယ် — ဒါပဲ MCP + API Key။ Claude က ဒီ password နဲ့ တံခါးဖွင့်ပြီး ရုံးထဲဝင်နိုင်တယ်။
04
ခွင့်ပြုချက် (Permission) အဆင့်တွေ
Claude ကို ရုံးတံခါးအထိပဲ ဝင်ခွင့်ပေးထားသလား — ဒါမှမဟုတ် ကိုယ်ပိုင်ရုံးခန်းထဲအထိ ဝင်ခွင့်ပေးထားသလား ဆိုတာ သင်သတ်မှတ်ရတယ်။
