n8n Docker container စတင်
docker run command
+
VPS Terminal
docker run -d \
  --name n8n \
  --restart unless-stopped \
  -p 5678:5678 \
  -v /opt/n8n/data:/home/node/.n8n \
  -e GENERIC_TIMEZONE="Asia/Yangon" \
  -e TZ="Asia/Yangon" \
  -e N8N_SECURE_COOKIE=false \
  docker.n8n.io/n8nio/n8n
ℹ️N8N_SECURE_COOKIE=false — HTTP (domain မပါဘဲ IP နဲ့ access) လုပ်တဲ့အချိန် login error မဖြစ်ဖို့ လိုသည်

Firewall Setup
လိုအပ်တဲ့ port တွေ ဖွင့်ပြီး မလိုတာ ပိတ်မည်
🔒
UFW Firewall configure
SSH · HTTP · HTTPS ဖွင့်မည်
+
VPS Terminal
ufw allow 22    # SSH — ဒါမပါရင် VPS ထဲ ပြန်ဝင်မရတော့ပါ
ufw allow 80    # HTTP
ufw allow 443   # HTTPS
ufw allow 5678  # n8n direct access (domain မပါဘဲ)
ufw enable
# "Command may disrupt existing ssh connections. Proceed with operation (y|n)?"
# y နှိပ်ပါ

ufw status
🚨ufw allow 22 ကို မဖြစ်မနေ ဦးဆုံး run ပါ — ဒါမပါဘဲ firewall enable လုပ်ရင် SSH ပြန်ဝင်မရတော့ပါ

Nginx + Let's Encrypt SSL
optional — production HTTPS
+
1
Domain DNS ကို VPS IP ကို point လုပ်ပါ
Hostinger Domain panel (ဒါမှမဟုတ် domain provider) → DNS Management → A Record → @ → VPS IP address ထည့်ပါ။ propagate ဖြစ်ဖို့ 5–30 မိနစ် စောင့်ရနိုင်သည်
2
Nginx + Certbot Install
VPS Terminal
apt-get install -y nginx certbot python3-certbot-nginx
3
Nginx Config ဆောက်ပါ
VPS Terminal
nano /etc/nginx/sites-available/n8n
ထဲမှာ ဒါ paste ပါ — your-domain.com ကို ကိုယ့် domain နဲ့ အစားထိုးပါ
nginx config
server {
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:5678;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        chunked_transfer_encoding off;
    }
}
Ctrl+X → Y → Enter ဖြင့် save လုပ်ပါ
4
Nginx Enable + SSL Certificate
VPS Terminal
ln -s /etc/nginx/sites-available/n8n /etc/nginx/sites-enabled/
nginx -t
# "syntax is ok" ထွက်ရမည်

systemctl restart nginx

# SSL Certificate (your-domain.com ကို ကိုယ့် domain နဲ့ အစားထိုး)
certbot --nginx -d your-domain.com
# email ထည့်ပါ → A (Agree) → N → Enter
5
n8n Container ကို Domain URL နဲ့ restart
VPS Terminal
docker stop n8n && docker rm n8n

docker run -d \
  --name n8n \
  --restart unless-stopped \
  -p 5678:5678 \
  -v /opt/n8n/data:/home/node/.n8n \
  -e GENERIC_TIMEZONE="Asia/Yangon" \
  -e TZ="Asia/Yangon" \
  -e N8N_HOST="your-domain.com" \
  -e N8N_PROTOCOL="https" \
  -e WEBHOOK_URL="https://your-domain.com" \
  docker.n8n.io/n8nio/n8n
✅Browser မှာ https://your-domain.com ဝင်ပြီး n8n ပေါ်ရင် SSL setup အောင်မြင်ပြီ
