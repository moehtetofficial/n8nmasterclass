Web Browser

Background Run (PM2)
Terminal ပိတ်လည်း n8n ဆက် run နေဖို့ — PC restart တိုင်း auto-start ဖြစ်ဖို့
⚙️
PM2 Process Manager Install & Setup
optional — production-like local run
+
1
PM2 Install
PowerShell (Admin) / Terminal
npm install -g pm2
2
n8n ကို PM2 နဲ့ Start
PowerShell (Admin) / Terminal
pm2 start n8n
pm2 save
pm2 startup
pm2 startup run ရင် command တစ်ကြောင်း output ထွက်မည် — ထို command ကို copy ပြီး ပြန် run ပါ (PC restart auto-start ဖြစ်မည်)
