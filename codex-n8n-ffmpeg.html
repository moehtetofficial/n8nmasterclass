📋 Codex Prompt — Docker
I want to set up n8n on my Windows 11 machine using Docker with FFmpeg included. Tasks: 1. Check if Docker Desktop is installed. If missing, download and install it via winget: winget install Docker.DockerDesktop 2. Verify Docker is running: docker --version 3. Create a Dockerfile with: - Base image: n8nio/n8n:latest - USER root - RUN apt-get update && apt-get install -y ffmpeg && apt-get clean - USER node 4. Build the image: docker build -t n8n-ffmpeg . 5. Run the container: docker run -d --name n8n --restart unless-stopped -p 5678:5678 -v C: 8n-data:/home/node/.n8n -e N8N_RUNNERS_ENABLED=true n8n-ffmpeg 6. Enable Execute Command node by setting environment variable N8N_RUNNERS_ENABLED=true inside the container (already included in step 5 via -e flag) 7. Verify n8n is accessible at http://localhost:5678 8. Verify FFmpeg is installed inside container: docker exec n8n ffmpeg -version 9. Ask for approval only when Windows requires administrator permissions 10. Provide step-by-step updates and notify if any command fails
📋 Codex Prompt — npm
I want to set up n8n on my Windows 11 machine using npm with FFmpeg included. Tasks: 1. Check if Node.js is installed: node --version. Required: v18 or v20 LTS only. If missing or wrong version, install nvm-windows from https://github.com/coreybutler/nvm-windows/releases, then: nvm install 20 && nvm use 20 2. Install n8n globally: npm install -g n8n 3. Verify installation: n8n --version 4. Install FFmpeg on Windows: - Check if winget is available - Run: winget install Gyan.FFmpeg - Verify: ffmpeg -version 5. Enable Execute Command node by adding to system environment: setx N8N_RUNNERS_ENABLED true 6. Close and reopen terminal, then start n8n: n8n start 7. Verify n8n is accessible at http://localhost:5678 8. To make N8N_RUNNERS_ENABLED permanent, it is already set via setx in step 5 9. Ask for approval only when Windows requires administrator permissions 10. Provide step-by-step updates and notify if any command fails
