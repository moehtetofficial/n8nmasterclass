MCP — Model Context Protocol
+

MCP (Model Context Protocol) ဆိုတာ Claude Desktop ကို external tool တွေနဲ့ ချိတ်ဆက်ပေးတဲ့ protocol တစ်ခုဖြစ်သည်။ n8n-MCP ကနေ Claude ကို n8n workflow တွေ create, edit, deploy လုပ်နိုင်အောင် direct access ပေးသည်။

Claude Desktop
→
n8n-MCP (Docker container)
→
n8n (localhost:5678)
ℹ️n8n-MCP က သပ်သပ် Docker container တစ်ခု — n8n container နဲ့ မတူဘဲ Claude ကနေ call လုပ်တိုင်း run ပြီး ပြန်ပိတ်မည် (--rm flag)

Config file ရှာနည်း — OS အလိုက် ရွေးပါ

1
File Explorer ဖြင့် ဖွင့်ပါ
File Explorer address bar မှာ ဒါ ရိုက်ပြီး Enter နှိပ်ပါ —
File Explorer Address Bar
%APPDATA%\Claude
claude_desktop_config.json ဆိုတဲ့ file ရှိမရှိ ကြည့်ပါ — မရှိရင် အသစ် create လုပ်ပါ
2
Notepad ဖြင့် ဖွင့်ပြီး config ထည့်ပါ
File ကို right-click → "Open with" → Notepad ဖြင့် ဖွင့်ပါ — အောက်ပါ content ကို ထည့်ပါ
claude_desktop_config.json
{
  "mcpServers": {
    "n8n-mcp": {
      "command": "docker",
      "args": [
        "run", "-i", "--rm", "--init",
        "-e", "MCP_MODE=stdio",
        "-e", "LOG_LEVEL=error",
        "-e", "DISABLE_CONSOLE_OUTPUT=true",
        "-e", "N8N_API_URL=http://host.docker.internal:5678",
        "-e", "N8N_API_KEY=YOUR_API_KEY_HERE",
        "-e", "WEBHOOK_SECURITY_MODE=moderate",
        "ghcr.io/czlonkowski/n8n-mcp:latest"
      ]
    }
  }
}
⚠️YOUR_API_KEY_HERE ကို Step 2 မှာ copy ထားတဲ့ key နဲ့ အစားထိုးပါ
